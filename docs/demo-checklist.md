# 线下验收演示清单

## 演示前

- 在 VS Code Remote WSL 中打开仓库，确认 Python 3.10 与 G++ 可用。
- 从任务面板启动后端和前端，打开 `/health`、`/docs` 和 Streamlit 首页。
- 执行 `python scripts/seed_demo.py`，准备管理员、普通用户和 A+B 题目。
- 在另一个浏览器会话保留普通用户登录，便于演示权限矩阵。
- 在 AI 页面填写百炼 URL、模型、Key 和手动确认的单价；不要展示或录制 Key。

## 10 分钟主流程

1. 展示 GitHub Conventional Commit 历史和绿色 CI，说明所有 API 使用 `async def`。
2. 管理员登录后连续切换顶部“账户概览 → 题库与评测 → 提交记录 → AI 智能命题 → 后台管理”，确认
   顶栏始终显示管理员身份，用户与语言列表正常加载且不再出现 401。
3. 管理员退出后确认回到登录页；普通用户再登录，确认后台管理入口隐藏、题目可访问，退出后
   再访问资料接口应得到 401。
4. 普通用户进入“题库与评测”，从默认题库点击“进入题目”，在详情与提交页面核对题面、限制
   与样例，再使用带行号、Tab 缩进和括号补全的编辑器提交 Python AC；观察 Pending 变为绿色 AC。
5. 切换顶部“提交记录”，确认每页 5 条并打开该记录，核对源代码和逐点日志；再提交 WA、RE 或 TLE，
   确认结果保留缩写、中文解释和各自颜色，而不是笼统显示“未通过”。
6. 管理员提交/重新评测 C++，再提交一份语法错误代码展示独立的 CE 标签与颜色。
7. 普通用户尝试查看他人私有日志得到 403；管理员公开题目日志后再次查看成功。
8. 管理员打开访问审计，使用用户/题目/结果筛选，展示同一用户的红色拒绝与绿色允许记录。
9. 在账户中心演示修改密码；管理员再更改用户角色为 banned，展示已有会话和再次登录均被拒绝。
10. 进入 AI 页面，确认默认打开“智能命题”；选择已保存模型，输入知识点、难度和边界要求，
    保持“自动”测试点策略，展示分阶段流式输出、请求次数、输入/输出/思考 Token 和人民币费用。
11. 先创建一项 AI 任务并中断，证明后台实际停止；再用“求斐波那契数列的第 N 项，结果对
    1000000007 取模，适合练习递推与取模”完成一项任务。确认进度显示双语言交叉运行，预览提示
    “Python/C++ 一致输出已校准 N 个答案”，展开核对模型原答案和校准答案，且校准本身未增加模型请求。
    切换 Python 3/C++14 参考解法后载入新增题目表单，确认自动跳转、答案采用校准结果且作者为模型名称。
12. 再生成一道明确要求淘汰暴力解的中等/困难题，展开“复杂度压力验证明细”：确认显示本地生成的
    大规模隐藏点、目标/禁止复杂度、正解实测后收紧的资源限制，以及低效探针在压力点的 TLE/MLE；
    连续生成两题时确认编号为 `AI0001`、`AI0002`。不要把超长压力输入当作公开样例展示。
13. 展示测试结果、Linux CI、架构图和实验报告源文件中的边界测试结果。
